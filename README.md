# Simple Portfolio (static)

This is a minimal, easy-to-edit static portfolio template with sections: Home, Skills, About, Projects, Contact.

How to use
- Open `index.html` in your browser to preview.
- Edit the content in `index.html`, `styles.css`, and `script.js` to personalize.
- Update the email in `script.js` (replace `you@domain.com`) to enable the contact mailto.

Deploy
- You can host this on GitHub Pages by creating a repository and pushing these files to the `main` branch, then enabling Pages in repository settings.
